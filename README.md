# ChristianRaun-FirmwareDevelopment
The firmware receives rpm on RPM variable and steps on displacement variable.

## Firmware Update over EtherCAT
**NOTE : Binary file name length must not exceed 16 characters.**

### MCC modules required for this project
- csp
- dev_packs
- CMSIS
- Ethercat
- MCC Harmony Core
